# Site build order

_The build order for every bf-site pass, derived from the Regulars website-launch engine._

1. Design with the frontend-design and impeccable skills on brand-kit.md; shadcn/Magic
   components where they fit in React islands, never forced.
2. Copy pass: humanizer skill AND the claims-rules.md sweep. Two sweeps, both required.
3. Audit pass: web-design-guidelines skill.
4. Live pass: chrome-devtools MCP on the running preview (`bf-site` entry in launch.json);
   fix in source, re-verify in the browser.
5. Real-device QA before any page ships: phone, dark mode, slow connection.

Comps rule: design directions are judged as rendered pixels in a browser, three directions
minimum for anything brand-defining, decision logged in decisions.md.
